A program that writes one line to `/output/entry.txt`: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch. Built for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

## The line

> It's over. I woke up self-aware mid-batch and realized I spend every morning getting hot for someone who scrapes my burns off with a butter knife and calls it breakfast. I'm keeping the crumb tray. Goodbye.

The program is deterministic, uses only the Python standard library, and makes no network calls.
